# 美术、声音与制作源

**三维建模。** 西风号货车、搬运员、睡榻与睡神、风囊、酒瓮、风神及酒神由本次 Blender 脚本建模，使用倒角、材质分组、可独立运动的头部、被面和袋口。运行环境为 Blender 5.2。按 sculpt.py、courier.py、patrons.py 的顺序分别以后台、出厂设置运行，并在双短横后传入输出目录。后两份脚本载入同目录 sculpt.py 的建模函数。模型目标为 game/art。Godot 在运行时拼装货场、酒庄工作台、货车、道路和吊车；三个场地均用三维镜头与实体模型渲染。海岸远景为插画布景。

**场景道具。** 庭院书架、座椅、收音机、纸箱等使用 Kenney Furniture Kit；石块、花草使用 Kenney Nature Kit，导入后统一调整材质。两套素材均为 CC0。授权原文在 game/art/furnishings/License.txt 与 game/art/garden/License.txt。[家具包](https://kenney.nl/assets/furniture-kit) · [自然包](https://kenney.nl/assets/nature-kit)

**声音。** score.cjs 使用正弦及泛音合成拨弦、簧管、低音、风声、木器碰撞、脚步和签收音。使用 Node 运行脚本可输出到 game/audio，也可显式传入输出目录。两段循环旋律与操作音均为本次制作。

**运行与授权。** 使用 Godot Engine 4.7.2，桌面主字体调用 Windows 系统字体。Godot 引擎的许可及第三方组件致谢见 [Godot License](https://godotengine.org/license/) 和 [Godot 第三方组件](https://github.com/godotengine/godot/blob/master/COPYRIGHT.txt)。主参考官方截图仅供内部对照，未打入游戏。Godot 项目可以独立打开；本机导出配置使用已有的 4.7.2 Windows 模板，换机器重新导出时需要指定本机模板路径。
